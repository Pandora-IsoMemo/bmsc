# Print constraint estimation model

Print constraint estimation model

## Usage

``` r
# S3 method for class 'ConstrainedLinReg'
print(x, cLevel = 0.95, fit = NULL, ...)
```

## Arguments

- x:

  model object of class
  [`ConstrainedLinReg`](https://pandora-isomemo.github.io/bmsc/reference/ConstrainedLinReg-class.md)

- cLevel:

  numeric: desired credible level

- fit:

  single model fit (return of getModelFits()-function)

- ...:

  arguments passed from or to other methods
