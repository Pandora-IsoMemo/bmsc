# Compute model average

Computes model weights according to measure

## Usage

``` r
get_avg_model(models_input, weights)
```

## Arguments

- models_input:

  Model list of class
  [`ConstrainedLinReg`](https://pandora-isomemo.github.io/bmsc/reference/ConstrainedLinReg-class.md)

- weights:

  Numeric vector of model weights

## Value

Model that is model average due to model weigths
