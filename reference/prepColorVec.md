# Prepare colour vector

Prepare colour vector

## Usage

``` r
prepColorVec(posBestModel, length)
```

## Arguments

- posBestModel:

  numeric: position of best Model

- length:

  numeric: Length of colour vector

## Value

Vector of length `length`. It contains "black" expect for the position
provided in `posBestModel`, which is "chartreuse4" (green)
