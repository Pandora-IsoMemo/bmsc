# Extract beta matrix from [`ConstrainedLinReg`](https://pandora-isomemo.github.io/bmsc/reference/ConstrainedLinReg-class.md) model

Extracts matrix of beta estimates

## Usage

``` r
getBetaMatrix(model, hasIntercept)
```

## Arguments

- model:

  model object: Model of class
  [`ConstrainedLinReg`](https://pandora-isomemo.github.io/bmsc/reference/ConstrainedLinReg-class.md)

- hasIntercept:

  logical: Does the model formula include an intercept?

## Value

matrix of estimates
