# Extract model names from model objects

Extracts the model formulae from a list of model objects of class
[`ConstrainedLinReg`](https://pandora-isomemo.github.io/bmsc/reference/ConstrainedLinReg-class.md).
Elements that are superfluous for reading (e.g., brackets) are removed.

## Usage

``` r
prepModelNames(models)
```

## Arguments

- models:

  List with models of class
  [`ConstrainedLinReg`](https://pandora-isomemo.github.io/bmsc/reference/ConstrainedLinReg-class.md)
